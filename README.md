# Cardiac Rhythm Specialists

Professional medical practice website for Cardiac Rhythm Specialists, Inc. and Dr. Leo Polosajian in California.

## Stack

- React
- Vite
- Tailwind CSS
- TypeScript

## Scripts

```bash
npm run dev      # start the local development server
npm run build    # type-check and production build
npm run preview  # preview the production build
npm run lint     # run oxlint
```

Website content has not been built yet. This repository currently contains the initialized project structure and development environment.
